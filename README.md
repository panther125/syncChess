# 同步象棋 Sync Chess

废除红先黑后：每一回合双方**同时、秘密**提交一步着法，揭示后按同一盘面快照**并行结算**。
棋盘、棋子、走法完全沿用中国象棋，冲突裁决借用军棋的等级机制——同格争夺比等级、移动中的炮必胜、路径交叉则同归于尽。

纯前端本地对战，无后端、无联网、无账号。

## 运行

```bash
cd app
npm install
npm run dev        # http://localhost:3000
npm run build      # 产物输出到 app/dist
npm run preview    # 本地预览构建产物
```

cd app

node node_modules/.tmp/engine.test.mjs

## 两种玩法模式

- **人机对战**：你与电脑在同一轮内各自秘密决策，揭示后统一结算；电脑按 1 层搜索给每个合法着法打分（复用同一套结算器）。
- **双人同屏**：一台设备轮流秘密决策。红方提交后遮屏交接，黑方在完整限时内决策，黑方视角自动旋转 180°，随后双方着法同时揭示。

## 回合流程

1. **秘密决策**：限时内各选 1 枚己方棋子 + 1 个合法落点，或按兵不动；超时视为按兵不动。
2. **同时揭示**：两条着法箭头同时亮出。
3. **并行结算**：全部基于回合开始快照判定，先同格争夺，再路径交叉，最后独立落点。
4. **进入下一回合**：吃将即胜；双方无子可动、连续 60 回合未吃子判和。

## 冲突裁决

| 情形 | 结果 |
| --- | --- |
| 双方争同一格 | 等级高者占格，低者被吃；等级：帅/将 7 > 车 6 > 马 5 > 炮 4 > 士/象 3 > 兵/卒 1 |
| 移动中的炮参与争夺 | 炮必胜，无视对方等级 |
| 双方都是移动中的炮争同一格 | 同归于尽 |
| 等级相同争同一格 | 同归于尽，该格留空 |
| 两条路径交叉（擦肩） | 同归于尽，两格留空 |
| 一方动、一方静 | 沿用传统吃子；静止的炮被移动棋子攻击时按等级裁决 |
| 吃到帅/将 | 立即获胜 |

其他规则：帅/将自身不可移动，仅因白脸将被吃而出局；底兵升格后等级视为 3 且可后退；连续 3 次双方同时按兵不动 → 强制进入 5 秒快棋。

规则页 `/rules` 内含完整裁决说明与本实现对设计文档空白处的解读。

## 目录结构

```
app/
  src/game/
    types.ts        类型定义
    rules.ts        走法生成、合法性过滤、中文记法
    resolve.ts      同步结算器（§6 全部裁决分支）
    ai.ts           启发式 AI（复用结算器做局面评估）
    useGame.ts      回合状态机、限时、悔棋、日志
    sound.ts        Web Audio 程序化音效（无外部音频文件）
    __tests__/      引擎用例
  src/components/   棋盘 SVG 渲染、面板、遮罩、设置弹窗
  src/pages/        Home / Game / Rules
同步象棋-玩法设计文档.md   玩法规格来源
```

## 技术栈

Vite + React + TypeScript（strict）+ Tailwind CSS + shadcn/ui。棋盘为纯 SVG 绘制，棋子位移用 CSS transition，无任何图片或音频资源。
